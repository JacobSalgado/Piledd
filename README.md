# Piledd
Book tracking website inspired by sites such as [Letterboxd](https://letterboxd.com/), [Backloggd](https://backloggd.com/), [AniList](https://anilist.co/), and [League of Comic Geeks](https://leagueofcomicgeeks.com/)

## MERN Stack
- MongoDB: Non-Relational Database
- Express: NodeJS web server
- React: JavaScript Frontend Library
- Node: JavaScript Web Server
